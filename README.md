# BantenIQ
An educational mobile application about Balinese banten, developed using Kodular.

## 📱 Project Overview
BantenIQ is an educational game about Balinese banten. The application helps users learn about various types of banten through learning materials, images, interactive quizzes, explanations, and score results.
The application was designed to make learning about Balinese culture more interesting, interactive, and accessible for young people.

## 🛠️ Development Tools
Kodular
TinyDB
Android

## 👩‍💻 My Role
UI/UX Design & App Development
I designed the application interface and developed the interactive learning and quiz experience using Kodular.

## 🎯 Target Users
Students, young people, and anyone interested in learning about Balinese banten.

## 🌺 Theme
Balinese Culture & Education

## 📚 Cultural Focus
The application introduces various types of Balinese banten along with their names, functions, and meanings through interactive learning materials and quizzes.

## 💡 Project Goal
BantenIQ aims to make learning about Balinese banten more engaging and accessible by combining cultural education with an interactive mobile game experience.

## 🎯 Project Purpose
BantenIQ was developed to:
- Introduce Balinese banten to young people
- Provide interactive learning materials
- Help users recognize different types of banten
- Introduce the function and meaning of banten
- Test users' knowledge through interactive quizzes
- Make learning about Balinese culture more enjoyable

## ✨ Main Features
- Splash Screen
- Introduction and Agreement Page
- Main Menu
- Banten Learning Materials
- Banten Information
- Interactive Quiz
- Multiple Choice Questions
- Correct and Wrong Answer Feedback
- Answer Explanation
- Quiz Progress
- Score Calculation
- Creator Information
